Engineered a TCP-like transport protocol over UDP, implementing automatic repeat requests (ARQ) for reliable delivery under 10% packet loss. Developed state-machine-based connection management using SYN/ACK/FIN messages and supported at least five simultaneous file transfers through a single multiplexed port.

**Technologies:** Computer Networks, UDP, Reliable Transport, State Machines
